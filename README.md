# Space Debris Decay Risk: interactive site

Static website for the CSE 587 Phase 3 project. Upload the Kaggle file
`space_debris_orbits_2026.csv` and the page runs the cleaning, the Gold tables,
the 80/20 split and the three models in your browser. The file is not uploaded
anywhere.

Files: `index.html` (layout and text), `app.js` (3D scenes, charts, upload flow),
`pipeline.js` (cleaning, features, split and models), `model.js` (prediction).
